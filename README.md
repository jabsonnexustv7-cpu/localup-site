# LocalUp Site

Landing page institucional da **LocalUp — Agência de Performance Local**.

## Estrutura

- `index.html` — página principal
- `styles.css` — identidade visual e responsividade
- `script.js` — animações leves de entrada e ano automático no rodapé
- `assets/logo-localup.svg` — logo vetorial da marca

## Proposta comercial incorporada

A LP apresenta os dois planos definidos:

### Presença Local
- Implantação: **R$ 990**
- Mensalidade: **R$ 197/mês**
- Prazo: **até 5 dias úteis**

### Performance Local
- Implantação: **R$ 1.290**
- Mensalidade: **R$ 697/mês**
- Prazo: **até 7 dias úteis**
- Verba do Google Ads paga separadamente pelo cliente

## Publicação

O projeto é estático e pode ser publicado diretamente em GitHub Pages, Vercel, Netlify ou Cloudflare Pages.
